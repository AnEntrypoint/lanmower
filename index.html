About

Two stacks. They overlap. Under AnEntrypoint there is a P2P layer built on Hyperswarm, and an agent runtime (plugkit, gm, agentgui, the ACP bridges, a pile of Claude and Anthropic glue) that lets coding agents talk to each other across models and wire formats.

The rs-*, plug*, and gm repos below form a working agent platform. Codebase search, code execution, learning memory, and a state-machine discipline. agentgui is the GUI on top. The blockchain and hyper-* work is the same family of problems: distributed consensus without a central authority.
